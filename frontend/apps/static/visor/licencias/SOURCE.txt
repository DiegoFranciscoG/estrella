Visor (ESTRELLA) - third-party WebAssembly readers in this folder
================================================================

Both readers are used exactly as published; ESTRELLA did not modify, rebuild or patch them.
The build takes the .wasm files straight from the npm packages and serves them from /apps/assets/
with a content hash in the file name (frontend/apps/vite.config.ts). This folder holds their notices.

Corresponding source: https://github.com/mlightcad/libredwg-web/tree/v0.7.5
(tag v0.7.5, commit 5144ff4255b0e9c392118798297450ef6eda0b6e), with the build steps in its README.
Its JavaScript wrapper (also GPL-3.0) is bundled, minified, into the separate worker script that
Visor starts only to read a DWG file; its source is in the same repository and tag.

How Visor uses it: the reader runs as a separate program in its own Web Worker. Visor sends it
the bytes of a file and receives a drawing (SVG) or a DXF file back, by message passing only.
The worker script as a whole is therefore distributed under GPL-3.0. Besides the wrapper it holds
one ESTRELLA file, frontend/apps/visor/cad-bounds.ts (MIT, compatible with GPL-3.0), whose source
is in the ESTRELLA repository.
